### About Me

I'm an Information Systems student at the Federal University of Mato Grosso do Sul (UFMS) and an IT Technician from the Federal Institute of Mato Grosso do Sul (IFMS), focused on **back-end development**, **Java**, and **software engineering**.

I have 1 year of hands-on experience developing and maintaining a Java desktop management system (Swing and JDBC) integrated with a relational database for the UFMS Psychology Clinic, working on SQL queries, CRUD operations, role-based access control, LGPD data masking, and object-oriented component design.

👉 **Explore my full portfolio, projects, and interactive resume (PT/EN) at [benevidesluiz.github.io](https://benevidesluiz.github.io/).**

### 💻 Software Development Projects

- **Psychology Clinic Management System (Java, Swing, SQL — UFMS)** – 1-year software development internship maintaining the university clinic's desktop system: restored CRUD flows, fixed SQL update queries, implemented logical deletion (*soft delete*), LGPD role-based data masking, and standardized Swing UI components.
- **[AgeCon — Contact Management System](https://github.com/BenevidesLuiz/AgeCon) (Java, Swing, JDBC, MySQL / MariaDB)** – Desktop CRUD application structured into `model`, `dao`, `controller`, and `view` layers using Java interfaces, `PreparedStatement` queries, and a normalized relational schema with foreign-key constraints.
- **[Movie Catalog REST API](https://github.com/BenevidesLuiz/atividadesweb) (JavaScript, Node.js, Express, SQLite, Jest)** – Layered back-end REST API (`routes`, `controllers`, `services`, `repositories`, `models`) with parameterized SQLite persistence, session authentication (`express-session`), and automated unit/integration tests with Jest and Supertest.
- **[MusicPlayer](https://github.com/BenevidesLuiz/Player-de-Musica) (Java JDK 25, Swing, JavaFX, yt-dlp, ffmpeg)** – Desktop audio and video player (`.mp3`/`.mp4`) combining Swing and JavaFX with external CLI process integration (`yt-dlp` and `ffmpeg`) for media download and format conversion.
